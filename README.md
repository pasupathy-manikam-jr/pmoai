# PMFAI — Personal Mutual Fund AI

A personal, self-hosted tool for tracking and analysing a Malaysian unit-trust
portfolio. It captures your own fund data and holdings, keeps a local history,
and runs an AI advisor over it — fund-by-fund verdicts, a whole-portfolio
review, a what-if switch simulator, price triggers, and a market dashboard.

Everything runs on your own machine against a local database. Your portfolio
data never leaves it.

## What it does

- **Fund catalog** — every fund with price/return data, filterable by series
  (Public / e-Series / PB / PRS), type, Shariah status, and a buy/hold screen.
- **Portfolio tracking** — your holdings with cost, current value, gain/loss,
  and money-weighted annual return (XIRR) derived from your own statements.
  Handles the same fund held across multiple accounts (per-account breakdown).
- **What-if switch simulator** — model a switch before you make it: sales
  charges, series/no-switch rules, realised gain/loss, risk (volatility) change,
  and how the moved money would compound.
- **AI review** — a per-fund analysis and a whole-portfolio memo. The LLM
  provider is swappable (a hosted API for production, or a local model for
  testing); it is grounded on your captured prices plus ingested fund-review
  data, and writes in plain English.
- **Price triggers & alerts** — watch a fund for a buy-below / sell-above price;
  get a desktop notification and an in-app banner when it is reached.
- **Transactions ledger** — your full transaction history from statement PDFs,
  plus a view of submitted-but-not-yet-processed (float) transactions.
- **Market dashboard** — live index mini-charts aligned to your exposures
  (US tech, gold, crude oil, Jakarta, India, USD/MYR, Bursa KL).

## How data gets in

The provider's website is not scraped by a server. A small **Tampermonkey
userscript** (in `tools/`) runs in your own browser while you are logged in,
reads the pages you open (prices, holdings, statements), and posts them to the
local app over a token-protected endpoint. Fund-review and statement PDFs you
download are parsed by artisan commands into the database. Nothing is automated
against the provider without you driving it.

## Tech stack

- **Laravel** (PHP) + **PostgreSQL** (with `pgvector` for embeddings)
- Local **Ollama** embeddings for semantic search over ingested commentary
- Pluggable LLM providers (hosted API or local)
- A Tampermonkey userscript for browser-side data capture

## Setup (local, personal use)

```bash
composer install
cp .env.example .env
php artisan key:generate
# set your DB, LLM provider keys, and PMOAI_INGEST_TOKEN in .env
php artisan migrate
php artisan serve
```

Then install `tools/pmoai.user.js` in Tampermonkey and set its token to match
`PMOAI_INGEST_TOKEN`. See `ARCHITECTURE.md` for the full data model and flow.
